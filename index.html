Panduan Penyimpanan ke GitHub & GitHub Pages

Berikut adalah langkah-langkah mudah untuk menyimpan aplikasi web ini ke repository GitHub Anda dan mengaktifkannya secara online melalui GitHub Pages:

1 Buat Repository Baru di GitHub

Buka github.com, login, lalu buat repository baru (misal: nama repository absensi-sholat-dhuha). Set repository ke Public.

2 Simpan File ini dengan Nama index.html

Salin seluruh kode dari aplikasi web ini dan simpan ke dalam file komputer Anda dengan nama persis index.html.

3 Upload File ke Repository

Di halaman repository GitHub Anda, klik tombol Add file > Upload files. Tarik dan letakkan file index.html ke area tersebut, lalu klik Commit changes.

4 Aktifkan GitHub Pages

Masuk ke tab Settings di repository Anda > Pilih menu Pages di sidebar kiri > Pada bagian Build and deployment (Branch), pilih main (atau master) dan folder / (root) > Klik Save.

Selesai!

Tunggu 1-2 menit, aplikasi web absensi sholat dhuha Anda kini sudah online dan dapat diakses melalui link GitHub Pages yang disediakan!
